## 📌 Project Overview

This project performs an end-to-end analysis of the Netflix content catalog using **Python, SQL and Tableau**.

The objective is to clean and analyze Netflix data, identify meaningful content trends, answer business questions using SQL, and present the findings through an interactive Tableau dashboard.

### 🔎 The project covers:

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Netflix Movies vs TV Shows analysis
- Release-year trends
- Content acquisition trends
- Genre distribution
- Country-wise content distribution
- Rating analysis
- Movie duration analysis
- TV show season analysis
- Director analysis
- SQL-based business queries
- Interactive Tableau visualization
